Example 1

Write the place value of the digit in number 9.

Solution

The number 9 has only one digit.

Hence, 9 is in the ones place.

Example 2

Write the place value of the digit in number 4.

Solution

Number 4 has only one digit.

Therefore, 4 is in ones place.

Recognising the place values of digits in ones and tens

The first place from the right of a number is called ones.

The second place is known as tens.
